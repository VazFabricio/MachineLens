Installation
============

You can install MachineLens using ``pip`` or ``uv``:

.. code-block:: bash

   pip install machinelens

For a faster installation, you can use `uv <https://github.com/astral-sh/uv>`_:

.. code-block:: bash

   uv pip install machinelens

Requirements
------------

MachineLens requires Python 3.11 or later and the following packages:

- `scikit-learn <https://scikit-learn.org/>`_ >= 1.7.2
- `numpy <https://numpy.org/>`_ >= 2.2.6
- `pandas <https://pandas.pydata.org/>`_ >= 2.3.3
- `plotly <https://plotly.com/python/>`_ >= 6.3.1
- `scipy <https://scipy.org/>`_ >= 1.11.0
- `shap <https://shap.readthedocs.io/>`_ >= 0.49.1
- `statsmodels <https://www.statsmodels.org/>`_ >= 0.14.6

All dependencies are installed automatically when you run ``pip install machinelens``.
